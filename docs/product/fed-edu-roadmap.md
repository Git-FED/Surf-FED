# FED-EDU product roadmap

This scaffold keeps the existing Surf FED browser project intact while adding FED-EDU as a parallel web/mobile product layer. Phase 1 is the PWA shell and content migration. Phase 2 adds authenticated profiles and progress. Phase 3 adds community moderation and projects. Phase 4 packages the shared web build with Capacitor. Phase 5 hardens messaging, privacy, recovery, and abuse prevention.
