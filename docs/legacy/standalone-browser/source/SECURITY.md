# Security Policy

## Supported Versions

We release patches for security vulnerabilities in the latest stable version only.

| Version | Supported |
| :--- | :--- |
| Latest stable (v2.x) | ✅ Yes |
| Older versions (v1.x) | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, send a private report to:

- **Email**: `security@fedpromptly.com`
- Or via GitHub's **"Report a vulnerability"** feature (under the Security tab of the repository).

Please include:
- A clear description of the vulnerability.
- Steps to reproduce it.
- Any potential impact or exploit scenario.

We will respond within **48 hours** to confirm receipt and will work on a fix as soon as possible. Once fixed, we will credit you in the release notes (unless you prefer to remain anonymous).

## Disclosure Policy

- We will privately acknowledge the reporter.
- We will fix the issue and test it.
- We will release a patch and publicly disclose the vulnerability **after** the fix is released.

Thank you for helping keep Advanced Browser secure! 🔒
