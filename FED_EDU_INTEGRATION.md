# FED-EDU integration

The FED-EDU React + Vite application has been added under `apps/web` without replacing the Surf FED Electron or Tauri browser applications. `apps/mobile` contains the Capacitor configuration for packaging the shared web build. Shared package placeholders, Supabase migrations, security notes, product roadmap, mobile build notes, and the mute-all-tabs promotion assets are included.

Run the web app:

```bash
cd apps/web
npm install
npm run build
```
