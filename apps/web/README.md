# FED-EDU web app

React + Vite PWA shell added alongside the existing Surf FED browser project. It includes Home, Courses, Community, Wiki/Dictionary, Blueprints, Profile, and Messaging routes, structured local content data, responsive navigation, offline fallback, and the mute-all-tabs promotion asset library.

```bash
npm install
npm run dev
npm run build
```

Supabase and authenticated messaging are intentionally scaffolded, not claimed as production-ready. See `../../docs/product/fed-edu-roadmap.md` and `../../docs/security/fed-edu-security.md`.
